What this means

    Checklist

    Each row links to the Microsoft Learn page behind the requirement. Rows marked best-effort detection come from static pattern scanning, not execution.

    Nothing is stored

    Your .pbiviz is streamed into memory, unzipped, analyzed and discarded within a single request. It is never written to disk and never logged.

    What we count

    Two numbers only: how many files were checked, and how many recommendations were shown. No file names, no IPs, no results. See the numbers.

    Where the AI fits

    Only the derived JSON result — score, rule IDs, reasons — is sent to a language model to write the summary. Your file and your code are never sent anywhere.
